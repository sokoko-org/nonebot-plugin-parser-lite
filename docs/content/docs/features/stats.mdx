插件会记录每次解析（成功与失败），并把统计结果渲染为图表卡片。天数参数默认为 `7`，范围为 1 到 `plite_stats_max_days`。

```text
@机器人 解析统计          # 当前会话近 7 天（默认）
@机器人 解析统计 30       # 当前会话近 30 天
@机器人 全局解析统计 90   # 全部会话近 90 天（仅 SUPERUSER）
```

| 指令 | 权限 | 内容 |
| :--- | :--- | :--- |
| `解析统计` | SUPERUSER / 群主 / 管理员 | 当前会话的解析趋势与平台排行 |
| `全局解析统计` | SUPERUSER | 全部会话的解析趋势、平台排行与会话排行 |

<StatsPreview />

卡片包含：总数 / 成功率 / 失败 / 日均 / 峰值概览、每日趋势、24 小时活跃时段、平台排行，全局统计额外附带会话排行。

## 相关配置

| 配置项 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `plite_stats_max_days` | `365` | 可查询的最大天数 |
| `plite_stats_top_targets` | `10` | 全局统计中展示的会话数量，其余合并为「其他」 |

统计卡片同样由主题渲染，主题作者可以通过 `stats.html.jinja` 自定义样式，见 [统计图模板](/docs/themes/stats)。
