日常使用中**不需要任何指令**，发送链接即可触发解析。下面这些指令用于管理与附加功能。

| 指令 | 参数 | 权限 | 需要 @ | 说明 |
| :--- | :--- | :--- | :---: | :--- |
| `开启解析` | 可选目标 ID | SUPERUSER / 群主 / 管理员 | 是 | 开启当前会话的解析 |
| `关闭解析` | 可选目标 ID | SUPERUSER / 群主 / 管理员 | 是 | 关闭当前会话的解析 |
| `bm` | BV 号 [分P]，或引用一个链接 / 卡片 | 所有人 | 否 | 下载 B 站视频的音频 |
| `blogin` | - | SUPERUSER | 是 | 扫码获取 B 站凭证 |
| `解析统计` | 可选天数 | SUPERUSER / 群主 / 管理员 | 是 | 当前会话近 N 天的解析趋势与平台排行 |
| `全局解析统计` | 可选天数 | SUPERUSER | 是 | 全部会话近 N 天的趋势、平台排行与会话排行 |
| `xz` / `下载` | - | 所有人 | 否 | 仅[懒下载模式](/docs/features/lazy-download)下可用，下载上一条解析的媒体 |

## 开启与关闭解析

- 不带参数时，群聊和频道中的指令作用于**当前会话**，私聊中的指令作用于**当前用户**
- 超级管理员可以指定其他目标：群聊中填写群号，私聊中填写用户 ID
- 私聊中关闭解析后，该用户在同一平台的私聊、群聊和频道中都**不能触发解析**

```text
@机器人 关闭解析
@机器人 开启解析 123456789
```

开关状态持久化保存在插件数据目录，重启后依然有效。

## bm：下载 B 站音频

```text
bm BV1CtYu6DE11
bm <BV号> 3        # 多 P 视频取第 3 P
```

第二个参数为分 P 序号，默认第 1 P。也可以**引用**一条包含 B 站链接或分享卡片的消息再发送 `bm`，插件会自动从被引用消息中提取 BV 号（包括展开 `b23.tv` 短链）。

音质上限由 [`plite_bili_audio_quality`](/docs/features/bilibili#音质) 决定，最终转码为 MP3 发送；开启 `plite_need_upload_audio` 时以群文件形式上传。

## 解析统计

```text
@机器人 解析统计
@机器人 全局解析统计 30
```

详见 [解析统计](/docs/features/stats)。
