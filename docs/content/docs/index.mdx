`nonebot-plugin-parser-lite` 是一个 [NoneBot2](https://github.com/nonebot/nonebot2) 插件。群友发出的分享链接会被它自动识别，插件随后拉取视频、图文、音频和评论区，并渲染成一张可以直接在群聊里阅读的卡片。

<Showcase />

## 它能做什么

- **零指令触发**：识别链接、短链、BV / av 号、QQ 小程序与分享卡片
- **30+ 个平台**：B 站、抖音、微博、小红书、知乎、贴吧……以及 6 个音乐平台
- **评论区渲染**：热评与楼中楼直接画进卡片
- **富文本还原**：文字、图片、贴纸、链接、引用、投票、Live Photo
- **发送方式可调**：自由组合卡片 / 正文 / 封面 / 视频 / 音频，支持合并转发与懒下载
- **主题系统**：Jinja2 + CSS 自定义渲染主题，按时间自动切换日夜模式
- **解析统计**：按会话或全局查看解析趋势与平台排行
